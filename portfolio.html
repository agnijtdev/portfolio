Projects

Selected technical work in networking and machine learning.

01
Self-Driving Dynamic Routing & BGP over Secure Transport

A Docker-based virtual enterprise network built on BIRD, implementing multi-area OSPF, eBGP, BFD, ECMP, Graceful Restart, and LLGR to evaluate routing resilience under network failures. Secure BGP transport was implemented and evaluated over plain TCP, TLS, QUIC, TLS-AO Static, and TLS-AO Dynamic, including Anycast and multihoming failover scenarios driven by certificate-based configuration.

02
MalVision

A malware classification pipeline that converts raw .exe / .dll binaries into grayscale images for static analysis, avoiding signature-based scanning or sandboxed execution. A VGG16 CNN was fine-tuned via transfer learning on the Malimg dataset and validated with confusion-matrix analysis, then deployed as a full-stack Flask and Bootstrap web app for real-time classification.
